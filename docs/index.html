A Claude Code plugin · free for personal use

whatdid

Know what the AI changed before you click Accept.

An AI agent just edited your project. whatdid tells you, in plain words, what changed, what's risky, how to check it and how to undo it. Then it plays the whole thing back as a 3D building: good changes build up, risky ones break what's below.

▶ Try the live demo Install in Claude Code View on GitHub

This is a real replay of a demo coffee-shop site. Drag to rotate, tap a floor or a crack, or press ⏮ Restart.

Without whatdid / with whatdid

What you see now

- .env
+ MAILER_API_KEY=sk-…
- "port": 3000
+ "port": 8080
- old-promo.txt
… and hundreds more lines. Accept?

What whatdid tells you

🔴 Your secret key could get uploaded. .env was taken off the never-upload list.

🔴 A file was deleted that you didn't ask about.

🟡 The site now opens at :8080, not :3000.

↩️ Undo all of it: git stash -u

What you get

Plain wordsWhat changed, grouped by what was done, in about 12 lines. No diff reading.
Risks you can't missFixed rules catch leaked keys, deleted files, deploy and database changes, and a risky commit or push is paused to ask you first. Secret values are never shown.
Check and undoWhere to click to check it worked, and one copy-paste command to undo it all, or just one file.
3D replayEvery step on a building you can rotate. Each crack is labelled with the step that caused it.

Install in 30 seconds

In Claude Code, type these one at a time, then start a new session:

/plugin marketplace add TonyIsFool/whatdid
/plugin install whatdid@whatdid

Then ask the AI for a change and type /whatdid. Needs Claude Code and git. No API key, no account, nothing sent anywhere.
